# 产品状态矩阵与生产发布门禁

> 状态：当前项目交付基线 v1.0。本文用于区分“代码存在”“自动化通过”和“可以生产发布”，避免把测试夹具或规划能力误写成已交付能力。

## 1. 状态分层

| 层级 | 判定标准 | 允许的产品表述 |
| --- | --- | --- |
| 代码实现 | 代码路径存在并可编译 | 已实现代码路径 |
| 自动化验证 | 单元、集成或 API 测试通过 | 已通过自动化验证 |
| 指定环境实证 | 在目标数据库、云枢、身份和网络环境中复测通过 | 已在指定环境验证 |
| 生产发布 | 身份、权限、网络、观测、回滚和运维门禁全部满足 | 可进入生产发布 |

当前 Web/MCP/CLI 共享 TaskGateway、幂等与证据契约属于“代码实现 + 自动化验证”；可信 OIDC/JWT、真实云枢写入/流程/导入、跨宿主网络 E2E、后台断线恢复和模板版本回滚仍不得标记为生产发布完成。

## 2. OpenClaw 体验 SLO

| 指标 | 目标 | 采集口径 |
| --- | --- | --- |
| 单轮领域委派完成率 | ≥ 99% | 同一 `turnId` 无宿主二次补查且返回终态 |
| 宿主二次调用率 | ≤ 1% | 非 `needs_input`/确认/显式 retry 的同轮再次调用 |
| `partial` 自动重试率 | 0 | `partial` 必须被宿主视为终态 |
| 结果信封完整率 | ≥ 99.9% | `completion/evidence/hostAction` 同时存在且可解析 |
| `hostAction` 遵循率 | ≥ 99% | 宿主按协议决定 compose/respond/ask/failure |
| 澄清轮次 | ≤ 2 轮 | 同一会话连续澄清次数 |
| 长任务终态返回率 | ≥ 99.9% | 任务最终收到 `final` 或可恢复状态 |
| MCP 断线恢复率 | ≥ 99% | 断线后能按 taskId 回放事件或读取终态 |
| 重复请求导致的云枢重复调用率 | 0 | 同一主体/安装实例/请求键只允许一次下游执行 |
| P95/P99 任务耗时 | 按 Skill 单独设定 | 从任务创建到终态，不把 SSE 首包当完成 |

## 3. 生产发布门禁

发布前必须逐项提供证据：

1. OIDC/JWT 可信主体校验、租户隔离和外部主体映射；
2. 云枢真实查询、写入、流程处理、导入和附件契约的 E2E 结果；
3. Web、MCP、CLI 跨网络调用共享执行器且结果一致；
4. 后台异步任务、断线恢复、状态/事件回放和取消语义；
5. 模板 Manifest 签名、审核、版本历史和一键回滚；
6. 凭据加密、密钥轮换、限流、重试、超时、告警和审计；
7. 数据脱敏、提示注入防护以及高风险写入确认票回归；
8. 灰度发布、回滚演练和故障注入结果。

H2、Mock、静态链接检查或单机浏览器验证不能替代上述生产门禁。

## 4. 历史测试与示例数据规则

历史测试中出现的具体对象名称、字段和数量只表示测试夹具或模板示例；它们不能作为 CPClaw 框架定位、通用 Skill 能力或生产数据承诺。业务逻辑只能进入已审核的 Skill/模板插件，框架层不得新增对象名称判断。
