# CPClaw UI 设计规范

## 1. 目标与边界

CPClaw 的页面必须共享同一套信息层级、交互位置和主题令牌。业务 Skill 可以组合页面内容，但不得在页面中重新定义颜色、字号、间距或主题状态。亮色和暗色只覆盖语义颜色，不改变布局尺寸与交互顺序。

## 2. 设计令牌

唯一实现入口为 `web/src/style.css`，令牌分为基础量（`--cp-space-*`、`--cp-font-*`、`--cp-radius-*`）和语义量（`--cp-bg-*`、`--cp-text-*`、`--cp-border-*`、`--cp-brand-*`、`--cp-state-*`）。默认亮色，`html.cpclaw-theme-dark` 覆盖暗色语义量。页面只允许消费 `--cp-*`，过渡期可使用 `--settings-*`/`--chat-*` 别名，但不得新增页面私有色板。

基础尺度：间距 4/8/12/16/20/24/32/40/48px；正文 14/22px，辅助 12/18px，标签 13/20px，卡片标题 16/24px，页面标题 28/36px，指标 28/36px；控件高 32/36/40px；控件圆角 8px，卡片 12px，状态标签为 pill。

## 3. 页面骨架

- 普通页面使用统一 App Shell：侧栏宽 272px，顶栏高 56px，内容区左右内边距 32~48px，阅读列最大 1200px。
- `PageHeader` 固定为标题、描述、操作区三段式；标题左对齐，页面主操作位于右侧，次要操作紧邻其左侧。
- 聊天工作台允许三栏和全屏布局，但必须复用同一令牌、焦点态和主题机制。
- 移动端（<900px）折叠侧栏，<620px 表单改为单列，点击目标至少 44px。

## 4. 组件契约

- 按钮：主操作使用 brand；次操作使用 surface + border；危险操作使用 danger 文本并二次确认。操作组间距 8px，主按钮在最右。
- 卡片：surface 背景、1px border、12px 圆角、20~24px 内边距，卡片间距 24px。
- 表格：表头 12px/20px semibold，标准行高 52px（紧凑 44px），单元格水平内边距 16px；操作列固定最右，顺序为查看→编辑→危险，超过 2 个收进更多菜单。
- 状态：成功/警告/错误/信息必须同时提供文字或图标，不得只依赖颜色。空、加载、错误状态使用统一最小高度 120px 的容器。
- 焦点：所有可交互元素提供 `:focus-visible` 2px brand 外环；动效 160~200ms，并遵循 `prefers-reduced-motion`。

## 5. 页面验收清单

检查标题层级、操作区位置、按钮尺寸、表格操作列、卡片间距、空/错/加载状态、亮暗主题可读性，以及 1440/1280/900/620px 下无横向溢出。禁止在业务页面新增裸十六进制颜色和非令牌字号。
