# 配置与元数据持久化需求方案

**状态：已确认实施。**

## 目标

云枢个人账号、管理员环境、模型配置、加密凭据、同步元数据、检索索引和元数据图谱必须在关系型数据库中保存。服务重启、前端刷新或切换页面不得造成已保存信息消失。

## 范围与规则

- 运行环境只允许连接持久化 MySQL 数据库；内存 H2 仅限自动化测试，不能用于本地验收、演示或生产服务。
- 设置页面只显示密码/API Key 是否已保存，绝不回显明文；密文记录随数据库备份恢复。
- 元数据同步完成后，应用、对象、字段、关系、API、搜索文档和图谱快照均可从数据库重新读取。图谱 JSON 导出只是副本，不能作为唯一数据源。
- 设置保存、模型保存和元数据同步均应为事务操作：成功时完整提交，失败时保留上一份可用数据。
- 启动时数据库不可用、迁移未完成或加密密钥缺失，服务必须明确启动失败，不得回退到空的内存库。
- CPClaw 运行数据库和可选向量数据库属于服务部署配置，不出现在管理员云枢环境表单中；该表单只保存用于设计态元数据同步的云枢连接。

## 验收标准

1. 保存个人云枢账号、管理员云枢环境、模型并同步元数据后，受控重启服务；读取结果与重启前一致，个人账号复用管理员环境地址，敏感值仍只显示“已保存”。
2. 启动日志能识别持久化数据库类型；使用 `jdbc:h2:mem:` 时启动被拒绝。
3. 数据库迁移由 Flyway 管理，备份与恢复后设置、模型、元数据和图谱快照可读。
4. 加密密钥变更须走迁移流程；未经迁移直接换密钥时不得将旧凭据误判为丢失。

## 非目标

附件二进制文件仍由受管文件/对象存储保存，数据库只保存附件索引与校验值；本需求不把文件内容写入配置表。
### 凭据恢复状态

系统区分“未配置”“可用”和“已保存但当前无法解密”三种状态。后者不代表配置被删除：数据库中的密文保留，用户需在原配置入口重新录入密码或 API Key，验证成功后覆盖同一凭据记录。界面不得展示 AES、密钥或 `Failed to decrypt credential` 等技术异常。

模型配置支持删除。删除只移除模型配置及其加密 API Key，不级联删除历史会话、消息、审计日志或 Token 记录；删除前必须二次确认。
