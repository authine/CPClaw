# 系统设置工作台补全需求方案

**状态：已确认实施。** 本需求只调整 CPClaw 的系统设置入口与连接验证，不改变对话主页业务内容。

## 1. 目标与边界

系统设置是同一工作台内的管理区域：管理员维护云枢环境、元数据与 Agent 模型；普通用户维护个人云枢账号，不应因管理页面改版而失去已有元数据查看入口。

本轮不新增云枢业务写操作，不把模型连通性测试表述为模型质量评估，也不回显凭据。

## 2. 信息架构

左侧菜单按职责拆分：

1. **云枢环境连接**（分组）
   - 个人云枢账号：仅维护账号和密码；问数与业务操作复用管理员配置的云枢环境。
   - 管理员云枢环境：统一维护云枢地址、管理员账号与检索配置。
2. **元数据管理**
   - 元数据同步：从管理员环境同步应用、实体、字段、关系与 API，并显示同步结果。
   - 元数据查看：搜索及浏览已同步的应用、实体、字段、关系、API 与图谱状态。
3. **Agent 模型**：新增模型必须先验证本次输入的名称、地址与 API Key；验证通过且配置未改动后才能保存。已保存模型仍可单独复测。
4. **日志分析**：按时间、状态、模型和动态业务意图查看 Agent/模型调用次数、输入输出脱敏摘要、Token 使用量与耗时；筛选项来自实际执行记录，不在界面硬编码业务枚举。
5. **安全控制台**：查看真实配置状态、理解写操作门禁；不再承担日志查询入口。

## 3. 验收标准

- 两类云枢账号为独立子菜单、独立保存和独立测试；管理员未配置时，元数据同步不可执行并提示前往配置。
- 旧 `/metadata` 入口跳转至系统设置内的“元数据查看”；同步、搜索、浏览、图谱查看与重建继续可用。
- 元数据查看采用两级浏览：一级只展示应用目录与每个应用的资源数量；点击应用进入二级详情。详情仅展示当前应用的实体、字段、关联和 API，并支持从顶部切换应用或返回目录，禁止把多个应用的实体混在同一个长列表中。
- 新增模型页提供“测试连接”和“保存模型”两个连续动作：前者只验证本次表单输入，不创建模型或保存 API Key；成功后启用保存，任一连接字段变更即要求重新测试。
- 模型测试显示成功/失败和耗时，不显示 API Key、响应正文或供应商敏感错误；测试成功仅代表当前基础对话链路可用。
- 安全页不得使用重复的静态“锁”说明卡。页面只呈现三类有决策价值的信息：个人云枢、管理员云枢和模型凭据的脱敏配置状态；以及修改/删除必须确认的执行规则。
- 日志分析作为系统设置独立菜单，默认提供调用总数、成功/失败、输入/输出 Token、总 Token、平均耗时和分页明细；输入输出仅展示脱敏摘要，缺失 Token 显示“—”，不做字符估算。
- 业务意图由 Agent 基于用户目标、上下文和元数据动态理解；日志保留动态意图文本并支持筛选。查询、写入、删除、确认等内部操作能力属于安全执行分类，不应在业务意图下拉框中冒充固定业务类型。
- 若当前运行的后端尚未提供日志分析接口，页面必须说明“当前后端版本未包含日志分析接口，需要以持久化数据库配置启动新版后端”，不得展示框架原始 `No static resource` 文本，也不得伪造空统计为真实结果。
- 旧 `/audit` 保留为 Agent Run 技术追溯详情，聊天历史继续使用；系统设置和主导航不再把它作为日志分析主入口。
- 数据库、向量库、密钥轮换等后端部署配置不在安全页提供编辑入口，只以简短边界说明呈现。
- 所有设置子菜单支持 URL 直达、刷新恢复、浅深主题及窄屏布局。

## 4. 设置页视觉与交互基线

系统设置各子页面遵循同一套紧凑工作台节奏，不因页面类型改变排版语法：工作台头部复用对话页的 56px 高度、品牌标记 32px、工作台标题 14px/600；内容区页面标题使用 28px 左右的主标题、14px 辅助说明和状态标签；正文采用不超过 980px 的阅读列，避免宽屏中表单、说明和按钮被拉成无效长条。

连接表单按“字段组—部署边界—操作栏”排布：字段标签与输入框保持固定 8px 间隔，字段组间保留 20px，部署说明使用低强调的信息区并与保存/测试操作分隔，不能贴边、压住或包围按钮。页面卡片统一使用 12px 圆角、细分隔线和 20~24px 内边距；正文、帮助文字、菜单说明分别保持清晰的字号和对比度，不以超大标题或大面积浅灰文字制造层级。

该基线适用于个人云枢账号、管理员云枢环境、元数据同步/查看、Agent 模型与安全控制台；响应式下先折叠布局再缩短文字，禁止组件相互覆盖或出现横向滚动。

## 5. 元数据查看的加载反馈

元数据查看属于本地持久化数据的异步读取场景。首次进入时，页面显示紧凑的“准备工作区”载入卡，而不是以多张大尺寸假应用卡填充页面。载入卡明确说明正在并行读取应用目录、实体与关联、最近同步记录，并以轻量统计占位表达结果将出现的位置；其高度受控，避免先撑开整页再回填真实目录。加载提示不阻塞返回对话或刷新操作。

页面标题操作区同时显示最近一次**成功**元数据同步时间，数据源是同步日志，而不是应用或实体的单条 `syncedAt`。没有成功记录时明确显示“尚无成功同步记录”；同步日志暂不可读时显示受控提示，不以旧时间或空白误导用户。手动刷新保留当前数据和当前时间，只在按钮上展示加载状态，避免整页再次跳动。
