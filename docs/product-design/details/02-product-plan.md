# CPClaw 产品概要设计与路线图

> 文档类型：产品概要设计｜状态：当前基线。蓝图见 `../00-product-blueprint.md`；可验收需求见 `01-requirements.md`；交互视觉规范见 `../../design/ui-design-system.md`。

## 1. 信息架构

```text
CPClaw
├─ 对话工作台
│  ├─ 新建/历史会话
│  ├─ 流式任务过程与未读状态
│  ├─ 结果表格/报告/证据
│  └─ 澄清、确认、取消、续接
├─ 系统设置
│  ├─ 云枢连接与元数据同步
│  ├─ 模型配置与预检
│  ├─ Skill/分析模板治理
│  ├─ 用户自定义设置记忆
│  ├─ 平台设置记忆（仅超级管理员）
│  └─ 审计与运行日志
└─ 外部集成
   ├─ MCP 发布与安装实例
   ├─ CLI/Remote 任务转发
   └─ 接入验收与安全状态
```

页面只负责展示和交互，不复制云枢语义判断、对象匹配、分页、聚合或确认策略。菜单切换必须更新 URL，详情页可刷新直达；主题切换只替换设计令牌，不改变业务状态。

## 2. 核心交互对象

| 对象 | 展示内容 | 终态/动作 |
| --- | --- | --- |
| 任务过程 | 当前阶段、业务化摘要、耗时和等待信号 | 运行中、需补充、待确认、完成、失败、取消 |
| 结果体验 | 结论、数据范围、证据、缺口、图表/表格 | 查看明细、继续追问、导出（按权限） |
| 确认卡片 | 操作对象、影响范围、变更摘要、有效期 | 确认、拒绝、过期 |
| 元数据资源 | 应用、对象、字段、系统/业务字段分类、中文描述 | 查看详情、重新同步 |
| 记忆设置 | 用户自定义设置记忆；平台设置记忆仅管理员可见 | 查看、添加、删除、审计；会话记忆不展示 |

## 3. 对话任务流程

1. 用户提交自然语言目标。
2. 前端创建任务并显示等待态；模型开始输出后将会话加入侧边栏，完成后显示绿色未读点。
3. 后端通过统一 `TaskGateway` 执行；前端优先消费 `TaskExperienceEnvelope.visibleTrace`，旧 `AgentResponse` 仅作兼容映射。
4. 任务需要信息时，展示澄清问题；需要写风险确认时，展示确认卡片并暂停。
5. 任务完成后展示结果、证据、口径和下一步；用户点击会话或滚动到底部后清除未读点。

## 4. 多层记忆与可见性

- 用户会话记忆只保存在会话上下文和记忆存储中，用于当前对话连续性，不在系统设置页单独展示。
- 用户自定义设置记忆按登录主体隔离，用户可在设置页管理个人偏好、习惯和长期约定。
- 平台设置记忆按系统/租户范围保存，仅超级管理员可在设置页查看和维护。
- 运行期间可以存在任务级执行记忆，但它属于内部生命周期数据，不是独立的产品设置层。
- 所有记忆只作为受控上下文输入，不能提升权限、改变元数据约束或绕过确认。
- 无登录阶段固定默认主体为 `huangj`；切换到正式身份中心前，不宣称多用户隔离已完成。

## 5. Skill 与模板产品边界

Skill 是可安装、可注册、可授权的能力单元，必须声明输入、输出、权限、风险和生命周期。云枢 Skill 只提供元数据驱动的通用查询/分析/操作能力；具体场景通过声明式分析模板插件表达。

模板插件可声明触发提示、字段角色、受限算子和输出结构，但不能包含任意脚本、SQL、URL、凭据或未审核副作用。模板治理由超级管理员执行，运行时只使用已审核并发布的版本。

## 6. OpenClaw 产品体验

OpenClaw 只需调用高阶 MCP 工具提交一个 `DelegationSpec`。CPClaw 返回结构化结果、证据完成度、缺口和终态 `hostAction`：

- `respond_directly`：宿主直接将 CPClaw 结果交给用户，不再次追问 CPClaw。
- `ask_user`：宿主按问题补充信息后再发起一次委派。
- `open_cpclaw_confirmation`：宿主展示确认要求，确认后携带票据续接。
- `report_failure`：宿主说明失败原因和可执行的下一步。

OpenClaw 可负责跨 Skill 编排和最终语言组织，但不得修改数字、范围、口径、风险信号或证据缺口。

## 7. 版本路线

| 阶段 | 产品交付 | 验收门槛 |
| --- | --- | --- |
| P0 | 对话、设置、元数据、查询/分析、结果体验、MCP/CLI 基础 | 自动化回归、持久化重启、结构化结果契约 |
| P1 | 记录引用、受控新增/更新/删除、幂等与确认 | 真实契约、权限重验、过期/重放测试 |
| P2 | 附件提取和字段草稿 | 来源可追溯、失败可补偿 |
| P3 | 流程待办查询与处理 | 节点权限、重复提交、状态回查 |
| P4 | 多应用 DAG、更多 Skill、组织记忆、生产级身份 | 独立准入、网络 E2E、运维和回滚 |

## 8. 当前限制

真实云枢写入、流程处理、导入、跨断线后台恢复、OIDC/JWT、多租户和模板版本回滚尚未达到生产发布条件；不得仅凭接口存在或 Mock 测试通过就标记为完成。
