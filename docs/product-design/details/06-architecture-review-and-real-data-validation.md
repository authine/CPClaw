# 架构评审与真实数据验证需求方案

**状态：已确认实施。**

## 目标

在已配置真实数据库、云枢和模型环境的前提下，对 CPClaw 进行两轮独立架构评审和两轮完整测试，修复确认的问题，并区分自动化模拟验证与真实租户验证结论。

## 评审范围

- 持久化、Flyway、加密凭据和启动门禁；
- 元数据同步、检索、图谱与真实云枢运行态查询；
- Agent ReAct/Reflection、确认、审计、记忆和错误边界；
- 前端系统设置、密码掩码和接口契约。

## 测试规则

测试专家必须先做只读环境检查，确认 JDBC 产品不是 H2；真实测试只使用已配置账号，禁止输出秘密。写操作、删除、流程处理和模型调用成本较高的动作默认不执行，除非测试用例明确要求且有确认/回滚方案。

## 交付物

输出架构问题清单、修改记录、自动化测试结果、真实数据测试用例与结论、未解决风险和验收建议。
