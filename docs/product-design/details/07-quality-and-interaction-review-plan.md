# 全局体验与智能质量修订方案（2026-08）

## 目标

将 CPClaw 从“页面和接口可用”提升为“用户可理解、可验证、可恢复”的企业智能体体验。修订以跨页面一致性、场景任务质量和受控智能执行为三个共同能力，不为单一截图或单条问句添加特例。

## 范围与验收

1. **配置防错**：所有外部连接均测试当前输入；字段变更使测试结果失效；只有当前版本测试成功才允许保存。已保存凭据的复测与编辑态测试明确区分。
2. **统一交互**：聊天、设置、元数据和日志共享字号、间距、标题层级、加载/空态/错误态、确认与滚动规范；不出现无意义的长滚动或重复操作。
3. **主页面质量**：验证多轮修订、闲聊直答、问数/分析、流程只读、流程写确认、意图不明澄清和失败降级。每项必须验证最终回答、可见过程与数据/确认边界。
4. **反馈闭环**：只对助手回答展示互斥反馈；状态在刷新后保持一致，并可用于后续回答修订与审计。
5. **智能边界**：模型负责理解上下文与生成答案；Skill、元数据、权限、确认和审计负责约束业务执行。模型失败不得伪造业务结论。

## 非目标

本轮不新增未经云枢运行态契约验证的写接口，不把内部记忆或私有推理暴露给用户，也不把单次测试数据宣称为生产质量保证。

## 增补：执行过程可追溯与稳定布局

1. **完整可追溯**：运行中的执行过程是面向用户的业务化状态记录；新步骤只能追加，或完成同一生命周期步骤，不能因“紧凑显示”删除较早步骤。完成后的执行记录必须与运行过程一致。
2. **受控信息密度**：紧凑模式仅可减少字段密度和间距，不可裁剪执行历史。若后续步骤很多，可以提供明确的“展开全部”交互，但默认不能让已发生步骤不可恢复。
3. **稳定侧栏切换**：侧栏收起/展开时，内容区只允许一次确定的布局变更；禁止连续改变内容区宽度，导致图表、文本和输入框在动画期间反复重排。侧栏自身可使用独立的淡入淡出或位移动效。

### 执行过程验收

- 连续产生 5 个及以上步骤时，运行中和完成后均能查看第 1 个步骤；同一步骤从“执行中”转为“已完成”不重复出现。
- 收起或展开左侧栏时，消息、图表和输入框不出现连续横向抖动、闪烁或多次尺寸跳变。

## 增补：受控填单与确认卡片

1. **写操作语义**：新增、修改、删除是不同的业务动作。用户明确说“新建/创建/录入”时，系统应识别为新增；模型可补足对象和字段，但不能把已明确的写动作改写为另一种写动作。
2. **对象优先级**：写操作优先绑定可执行业务实体。元数据中同名字段、引用关系或报表只能作为线索，不能代替目标表单；例如“创建线索”应优先命中线索实体，而非某个包含“线索”字段的项目表单。
3. **可理解确认**：确认区展示“准备执行的动作、目标对象、影响说明、确认按钮”。它不得展示内部意图代码、schemaCode 或接口路径，也不得截断按钮、说明或风险边界。

### 确认交互验收

- “帮我创建一个线索”返回新增类意图，并绑定线索业务实体；模型规划不能将其改为修改类意图。
- 有待确认写操作时，确认卡片的完整标题、动作、对象、说明和按钮均可见；窄屏下可换行而不可裁切。

## 本轮管理工作台 UI 专项修订（2026-08-24）

- 系统设置沿用首页应用壳层基线：侧栏 288px、顶部 56px、导航标题 14px/20px、说明 12px/17px、正文 14px。
- 管理页正文最大宽度扩展至 1120px，表单卡片上限 960px，减少大屏右侧空白并保持内容起始线一致。
- ≤900px 时设置菜单改为与首页一致的抽屉模式，提供打开按钮、遮罩和 Esc 关闭；不再无入口地压缩成图标栏。
- 连接表单将“验证连接”和“保存配置”职责分开，保存按钮仅在当前表单版本验证通过后启用。

## Token 用量与调用审计分离（2026-08-24）

- **用量看板**独立承载按日、周、月的 Token 趋势，以及按模型的用量与调用次数分布，便于运营观察。
- **调用明细**只承载脱敏摘要、状态筛选、分页和单条详情，避免将看板、筛选和审计表混在同一页面。
- Token 仅采用模型服务返回的 usage；未返回 usage 的调用仍显示为一次调用，但不按文本长度估算。当前没有模型价格表，因此不展示费用或成本。

## 元数据同步可追溯性（2026-08-24）

- 元数据同步页面显示最近一次**成功**同步时间，避免以按钮点击时间或当前页面状态替代实际结果。
- 同步日志按开始时间倒序展示，并包含状态、对象范围统计、图谱规模、耗时和脱敏后的失败摘要。
- 每次同步尝试均记录；失败不覆盖或删除既有本地元数据，也不因图谱快照清理而丢失同步审计记录。
