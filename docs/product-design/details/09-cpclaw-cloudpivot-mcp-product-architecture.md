# CPClaw 云枢 Skill 核心能力产品架构

> **架构修订**：Yunshu Skill Gateway 是可独立部署和发布的产品能力；CPClaw Web、WorkBuddy、OpenClaw 均为宿主。外部宿主不得调用 CPClaw 对话 API 或确认页面。执行基线见 `docs/technical-design/details/22-yunshu-skill-executable-architecture.md`。

> 状态：架构基线｜适用范围：CPClaw 对外提供云枢能力的 MCP 服务，以及未来其他 OpenClaw 类宿主接入。

## 1. 产品定位

CPClaw 是一个可作为宿主使用的企业级 AI 工作台；Yunshu Skill Gateway 是可独立部署、发布和复用的云枢任务能力。WorkBuddy 及其他 OpenClaw 类产品直接调用 Yunshu Skill，不与 CPClaw 对话或 UI 交互。

Yunshu Skill 不修改云枢本身，也不要求云枢支持 MCP；协议转换、语义理解、元数据定位、权限边界、确认票、审计和结果生成均由 Skill Runtime 完成。

## 2. 产品边界

| 层次 | CPClaw 负责 | 宿主负责 |
| --- | --- | --- |
| 层次 | Yunshu Skill Gateway 负责 | 宿主负责 |
| 连接 | MCP/HTTP 协议、版本、限流和任务生命周期 | 保存服务配置并发起调用 |
| 身份 | 校验可信主体、租户和云枢权限 | 提供可信身份声明并展示登录状态 |
| 智能 | 意图理解、元数据匹配、任务规划和执行 | 将用户原话传入高阶入口 |
| 执行 | 查询、分析、表单、流程、确认票和幂等写入 | 不拼接云枢原子 API |
| 展示 | 返回结构化结果、追问、草稿和确认要求 | 在自身 UI/对话中展示并回传用户动作 |

## 3. 用户体验主线

用户只表达目标，例如“分析在建项目情况”。CPClaw 返回：

1. 已理解的目标和分析范围；
2. 已验证的业务对象、字段、枚举、关联关系和数据范围；
3. KPI、图表、表格、业务结论、风险和口径说明；
4. 可继续追问的问题；
5. 缺少证据时的澄清，而不是编造结论。

WorkBuddy 不需要知道 `schemaCode`、`apiCode`、字段编码或云枢内部接口。

### 3.1 经营分析的图文一体体验

对于“分析一下本月线索转商机情况”这类问题，用户看到的是一份连续的业务解读，而不是孤立的数字卡片：先给出结论摘要，再用指标卡说明线索量、商机量和可核验的平均转化用时，随后以业务链路图和趋势/阶段图解释变化，最后给出异常、数据范围、统计口径和依据。文字中的每个数字必须能在图表或指标中对应，关联关系不足时明确显示“暂不能判断”，不以同期总数替代转化结果。

同一报告在 CPClaw、WorkBuddy 或其他 OpenClaw 类宿主中均保持这份业务语义：支持结构化图表的宿主展示图文卡片，仅支持文本的宿主则获得同一图表的文字化数据和解释。

## 4. 核心 Skill 产品

首期 Skill 不是对象模板，而是能力模板：

- 通用对话 Skill：与业务系统无关的闲聊、解释和写作。
- 云枢查询 Skill：业务数据查询、筛选、分页和结果引用。
- 云枢数据洞察 Skill：动态指标、关联分析、图表和结论。
- 云枢表单 Skill：填单草稿、字段校验和确认提交。
- 云枢流程 Skill：待办、已办、发起流程查询和受确认处理。
- 云枢数据操作 Skill：修改、删除、Action 预览与确认。
- 云枢导入 Skill：Excel 解析、字段映射、行校验、预览和导入作业。

每个 Skill 必须声明输入槽位、证据要求、产物类型、风险级别、确认要求和完成条件，不声明任意接口地址或凭据。

## 5. 发布与运营

管理员在系统设置中配置云枢环境、同步元数据、启用“云枢 MCP 服务”，查看发布状态、能力状态、最近同步时间和调用审计。终端用户只在宿主中配置自己的云枢账号和密码。CPClaw 不持久化终端凭据。

运营侧需要查看调用次数、Token、响应时间、失败原因、澄清率、确认率、Skill 命中率、结果反馈和真实数据口径警告。

## 6. 产品验收原则

- 单一高阶入口即可覆盖查询、分析、填单、流程和操作，不要求宿主调用原子工具。
- 业务分析必须有证据和口径；无法验证时必须降级为澄清或数据不足说明。
- 所有写操作必须经过确认、幂等和审计。
- MCP 不支持图表渲染时，仍能直接呈现完整 Markdown 业务回答。
- 更换 WorkBuddy 或其他 OpenClaw 宿主时，不改变 CPClaw 内部 Skill 和任务运行时。
