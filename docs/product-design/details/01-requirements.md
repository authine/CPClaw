# CPClaw 规范性需求

> 文档类型：需求基线｜状态：当前 V1 需求。产品蓝图见 `../00-product-blueprint.md`，概要设计与路线见 `02-product-plan.md`；专项验收以 `../../test-cases/` 为准。

## 1. 背景与目标

CPClaw 面向采用云枢及其他企业系统的用户，提供可扩展、可治理的多 Skill 对话式任务入口。系统必须先理解用户目标，再由对应 Skill 基于其能力模型和已授权范围完成查询、分析或受控操作；不能依赖 CPClaw 框架中的固定业务对象词或预置行业判断。云枢 Skill 的能力模型采用同步元数据，但该机制不要求其他 Skill 采用相同实现。

## 2. 功能需求

### 2.1 对话与任务体验

- 支持新建会话、多轮上下文、历史持久化、Markdown、附件和流式输出。
- 任务过程只展示真实发生的业务化阶段；不得预先猜测步骤，不展示 Prompt、私有推理、内部编码、接口路径或凭据。
- 任务终态必须明确为完成、需补充、待确认、失败或取消；流结束而无终态视为失败。
- 结果必须提供来源范围、口径、证据完成度、缺口和可继续的下一步。
- Web 与 MCP/CLI 对同一目标必须使用同一运行时和同一结果契约。

### 2.2 Skill 与元数据

- Skill 通过注册表声明能力、输入输出、权限、风险、版本和生命周期。
- 云枢 Skill 必须先同步应用、对象、字段、关系、视图/表单操作等元数据，再基于本地索引和图谱定位目标。
- 系统字段与业务字段按同步元数据分类；分析默认优先业务字段，系统字段只用于技术过滤和审计。
- 未在本地元数据中验证的对象、字段、关系或 API 不得进入执行计划。

### 2.3 查询、分析与操作

- 查询/统计/分析必须由元数据和用户目标动态生成过滤、指标、维度、关联和呈现方式。
- 数量、金额、比例和分布由程序基于真实数据计算；模型负责规划、解释和语言组织。
- 新增、修改、删除、导入、流程处理、附件上传和不可逆 Action 必须经过计划、权限重验、确认、幂等和审计。
- 记录级后续操作必须引用当前会话保存的结果引用，不能全局重新搜索“第一条”。

### 2.4 多层记忆与管理员

- 用户会话记忆只作为当前对话上下文保存，不在设置页作为独立配置项展示。
- 用户自定义设置记忆按主体隔离，当前用户可以查看、添加和删除自己的长期偏好记忆。
- 平台设置记忆按系统/租户范围保存，仅超级管理员可以查看、添加、修改和删除。
- 三层记忆均只能作为受控上下文输入，不能提升权限、改变计划校验或绕过确认。
- 无登录部署固定使用默认主体 `huangj`，不得接受任意外部主体冒充。

### 2.5 OpenClaw 类宿主

- 对外提供唯一高阶业务工具 `yunshu_handle_request`（兼容 `cpclaw_cloudpivot_agent`）。
- 请求采用 `DelegationSpec`；返回 `TaskExperienceEnvelope`，并通过 `hostAction` 指示宿主直接回答、追问、请求确认或报告失败。
- `respond_directly` 时宿主不得再次改写任务或反复调用；跨 Skill 任务由宿主编排，但不得篡改云枢事实、口径和缺口。

## 3. 非功能需求

- 安全：凭据加密或外部密钥引用；日志、消息和 MCP 载荷脱敏；写风险操作可审计。
- 一致性：Web、MCP、CLI 复用 `TaskGateway → SkillRegistry → Skill Executor`。
- 可恢复：支持幂等 replay、continuation 票据、状态/事件查询和取消；后台断线恢复需通过生产队列后再宣称完成。
- 可维护：框架层禁止出现具体业务对象、行业词、字段别名和固定风险规则；业务场景只能由元数据或已审核模板插件提供。

## 4. 当前状态

| 需求域 | 状态 | 约束 |
| --- | --- | --- |
| 对话、持久化、流式任务、元数据、只读查询/分析 | 已实现并验证 | 真实数据规模、模型和权限环境会影响体验 |
| MCP/CLI 高阶委派、结构化结果、幂等/续接/取消 | 已实现并验证 | 生产网络身份仍需门禁 |
| 模板 Manifest 校验与发布治理 | 已实现并验证 | 历史版本回滚尚未完成 |
| 通用写入、流程处理、导入、附件字段映射、复杂 DAG | 方案/规划 | 需真实契约、权限、补偿和 E2E 证据 |

## 5. 验收原则

任何能力只有在代码路径、接口契约、自动化测试和必要的真实环境验证同时满足时，才能标记为“已实现并验证”。接口注册、Mock 成功或历史截图不能单独构成完成证据。
