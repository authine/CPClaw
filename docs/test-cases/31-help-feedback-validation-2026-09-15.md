# 应用帮助中心与问题反馈验收

| 编号 | 场景 | 验收 |
|---|---|---|
| HF-01 | 首页进入帮助中心 | 点击 CPClaw 首页帮助入口，进入 `/help` |
| HF-02 | 帮助内容分区 | 快速开始、业务场景、配置权限、常见问题可切换 |
| HF-03 | 提交反馈 | 填写类型、标题、描述后提交，后端返回成功 |
| HF-04 | 空反馈校验 | 标题或描述为空时前端阻止提交 |
| HF-05 | 反馈持久化 | 数据库 `user_feedback` 保存租户、主体、应用、状态和时间 |
| HF-06 | 运营查看 | 超级管理员可在系统设置的问题反馈页查询 OPEN 反馈并按状态、关键词筛选 |

当前已验证：前端构建通过、后端全量测试通过。真实浏览器交互、管理员身份切换和反馈状态流转仍需下一轮 E2E 验证。
