# 云枢 Skill 场景验证报告（2026-08-27）

## 验证边界

本轮使用 Spring Boot + H2 + Mockito 的受控测试环境，验证 Skill 的意图识别、元数据查询、结果分析和写风险门禁。该环境不等同于真实云枢租户；发起流程、填单、审核等写操作只验证“正确识别并阻断/生成确认要求”，不执行真实写入。

## 场景矩阵

| 场景 | 示例目标 | 期望 | 结果 |
| --- | --- | --- | --- |
| 数据查询 | 查询某业务对象列表/数量 | 进入 `query_data`，读取已同步元数据和云枢运行态 | 通过 |
| 数据分析 | 分析整体情况、趋势、分布 | 进入 `analyze_data`，输出证据范围与缺口 | 通过 |
| 待办查询 | 查看我的待办、已办、我发起的流程 | 进入 `workflow_query`，仅调用已验证只读契约 | 通过 |
| 发起流程 | 发起流程/提交流程 | 识别为 `workflow_action`，未通过真实写契约时阻断 | 通过（安全阻断） |
| 填单 | 新增/创建/填单/填表 | 识别为 `create_data`，进入确认门禁，不直接写入 | 通过（确认门禁） |
| 审核 | 同意/驳回/转交待办 | 识别为 `workflow_action`，不调用流程写接口 | 通过（安全阻断） |
| 修改/删除 | 修改、删除业务记录 | 识别写风险并生成确认计划 | 通过（确认门禁） |

本轮补充回归：`审核第一条待办` 已明确识别为 `workflow_action`；“查询/分析”使用只读范围可执行，“发起流程/审核/填单/修改/删除”在未开启可信写入范围时分别进入安全阻断或确认门禁，不能绕过云枢写接口。
