# 对话式系统操作验收矩阵（V1）

**状态：P0 受控试点已验证，生产门禁仍未全部关闭。** 自动化验证覆盖本地模拟云枢环境；真实租户、权限主体、记录版本和 API 幂等契约仍需外部联调。

## 1. 阶段门禁

| 阶段 | 验收范围 | P0 门禁 |
| --- | --- | --- |
| G0 | 执行底座 | 真实元数据快照、测试租户、API 白名单、权限矩阵、脱敏、审计、确认 TTL/重放阻断 |
| G1 | 智能问数 | 单对象查询/分析、多轮承接、已验证关系、多页口径、fallback 与样本警告 |
| G2 | 智能填单 | 文本/附件提取、字段来源、必填校验、缺项澄清、草稿、幂等创建和附件一致性 |
| G3 | 智能流程 | 当前用户待办/已办、节点动作、意见规则、状态重验、确认和结果回查 |
| G4 | 智能操作 | 结果集引用、精确记录 ID、差异/影响预览、确认后一次执行、版本冲突阻断 |
| G5 | 通用操作 | API 逐项契约验证、白名单准入、权限/风险/幂等/补偿和审计闭环 |

任一阶段存在未关闭 P0 安全缺陷，不得进入下一阶段或扩大 API 白名单。

## 2. 场景用例

### IQ：智能问数与关联分析

- 明确对象的计数、明细、筛选、分组和趋势必须调用真实运行态 API。
- 同名对象、显式应用路径、上一轮 `schemaCode` 必须保持正确归属。
- 跨对象只使用唯一元数据关系和真实关联键；关系不存在时澄清或并列展示。
- 返回中记录字段、过滤、关系路径、元数据版本、`total/returned` 和全量/样本口径。
- fallback、权限失败、分页不完整、日期/身份字段缺失不得生成确定性业务结论。

### FM：智能填单

- 每个字段值可追溯到用户输入、附件页码或表格单元格，并显示置信度。
- 必填、类型、枚举、权限和业务校验失败时进入澄清，不创建记录。
- 草稿可编辑；确认计划包含字段差异、目标表单、API、幂等键和影响范围。
- 重复确认只执行一次；创建成功但附件失败时返回部分成功和补偿状态。

### WF：智能流程

- 待办/已办按当前用户和授权范围隔离，不能混淆已办与待办。
- 处理前读取流程实例、节点版本、允许动作和意见规则；节点变化后计划失效。
- 审批、驳回、转交等动作必须确认，执行后回查新状态并写审计。

### OP：列表后智能操作

- 查询结果生成包含 `recordId`、行号、查询运行 ID、版本、权限范围和过期时间的引用。
- “第一条/刚才那条/这个客户”只能解析到唯一引用；不得重新全局搜索替代引用。
- 排序或过滤变化、引用过期、记录版本冲突、权限变化和批量超阈值均阻断执行。

### GA：通用对话操作

- 未同步对象、未验证 API、未知字段或未覆盖风险策略的请求必须澄清或拒绝。
- 每个新增 API 通过契约测试、真实测试租户联调、权限测试、失败/重试/幂等测试后才可启用。

## 3. 横向回归

覆盖未确认、过期、跨会话重放、修改确认输入、重复提交、取消与提交竞争、API 4xx/5xx、超时、DAG 局部失败、敏感信息脱敏、SSE 到历史审计恢复和移动端无横向溢出。每个通过项必须保留测试输入、元数据版本、计划摘要、API 摘要、结果和审计 ID。

### Agent 框架回归

- ReAct 事件顺序必须是实际发生的 `Observe → Think → Act → Reflect`，不得由前端猜测未来步骤。
- Reflection 失败、工具异常、置信度不足或风险升级时必须停止下游动作；不得无限循环。
- 记忆召回和写入必须在时间线与 Agent Run 中可见；敏感内容、失败猜测和未确认映射不得写入长期记忆。
- 用户纠正或稳定成功映射写入后必须带来源、置信度、TTL，并且不能覆盖精确编码和最新元数据。

## 4. 当前基线声明

现有智能问数/分析用例可作为 G1 基线；结果集引用、删除确认、确认计划哈希、重复确认阻断和记忆脱敏已在本地自动化测试中通过，可作为 G4 受控试点。附件字段映射、通用新增/更新、待办/已办和流程处理不得在验证前标记为已交付。
