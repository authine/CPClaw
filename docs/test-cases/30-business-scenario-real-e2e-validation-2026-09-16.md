# CPClaw 业务场景真实验收与阻断验证（2026-09-16）

本轮由独立测试视角执行。验收以当前真实主入口 `SettingsView → MetadataBrowserPanel`、本地运行服务和已同步云枢元数据为准；`MetadataView.vue` 只作为非主入口记录，不作为通过依据。只读场景使用真实服务和真实元数据，写入场景只验证 fail-closed，不创建业务数据。

## 执行环境

| 项目 | 证据 |

| 前端 | `http://127.0.0.1:5173/` HTTP 200 |
| 后端 | `http://127.0.0.1:8080/api/settings/models` HTTP 200 |

## 本轮安全修复

- 修正真实主入口 `MetadataBrowserPanel.vue` 的加载占位标签，将“关联”改为“动作数”。
- 修正真实主入口应用详情统计，将“关联”统计卡移除，保留实体、字段、动作数。
- 在真实主入口补齐列表/图谱模式记忆、实体关系图谱画布和 API 动作筛选的浏览器验收。
- 前端 `npm run build` 通过；该结果只证明编译，不替代浏览器交互验收。

## 缺陷与发布判断

1. **P0：真实 Provider 创建/回查已形成受控闭环，但真实网络中断后的 UNKNOWN 自动对账、外部身份和生产网络 E2E 仍未形成完整闭环。** 不能投产。
2. **P1：主入口图谱结构、模式记忆和 API 动作筛选已完成真实浏览器验收。**
3. **P1：真实查询/分析链路已执行；智能填单的真实字段定位、自然语言映射和确认前安全门禁已通过。经营分析仍受云枢日期字段覆盖不足阻断，不能作为经营结论交付。**
4. **P2：搜索采用宽松召回，`不存在的实体`仍能返回包含通用词“实体”的结果。** 需明确产品规则后再改为严格无结果或降低泛词召回权重。

### 当前发布结论

当前达到“真实元数据图谱浏览器验收 + 受控 Provider 创建回查 + 外部 Skill 本地认证链路验证”，但未达到“业务全链路验收通过”或“投产”。真实网络故障、企业身份矩阵和查询/分析/填单对话 E2E 仍是发布门禁。
