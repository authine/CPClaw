# Agent 模型新增前连通性验证用例

## 范围

验证新增模型的连接测试发生在保存之前，且不会把未确认配置写入数据库或泄露 API Key。

| ID | 场景 | 预期结果 |
| --- | --- | --- |
| MCV-01 | 未填完整连接字段 | 前端禁止测试并提示补全字段；保存不可用。 |
| MCV-02 | 输入有效配置后点击测试 | 调用 `POST /api/settings/models/test`；只返回成功状态、脱敏消息与耗时。 |
| MCV-03 | 预检失败 | 不创建模型、不保存 API Key，保存按钮继续禁用。 |
| MCV-04 | 预检成功 | 不创建模型；保存按钮启用。 |
| MCV-05 | 成功后更改名称、地址或 API Key | 预检状态失效，保存再次禁用。 |
| MCV-06 | 点击保存 | 仅在当前预检成功时创建模型，并将 API Key 仅以加密凭据保存。 |
| MCV-07 | 已保存模型复测 | 使用模型 ID，从服务端加密凭据读取密钥；浏览器不重复发送密钥。 |

## 非目标

通过连通性验证不表示模型质量、思考模式、复杂 Agent 规划或真实业务问数已经验收。

## 安全控制台回归

| ID | 场景 | 预期结果 |
| --- | --- | --- |
| SEC-01 | 打开安全控制台 | 显示个人云枢、管理员云枢与 Agent 模型的脱敏配置状态。 |
| SEC-02 | 点击配置状态行 | 跳转至对应系统设置子菜单。 |
| SEC-03 | 点击日志分析入口 | 保持在系统设置，进入日志分析子菜单，不展示任何凭据。 |
| SEC-04 | 检查规则与部署说明 | 写操作确认规则清晰可见；数据库、向量库仅说明后端部署边界，无编辑入口。 |

## 元数据层级浏览回归

| ID | 场景 | 预期结果 |
| --- | --- | --- |
| MDB-01 | 打开元数据查看 | 默认展示应用目录，不直接罗列跨应用实体。 |
| MDB-02 | 查看应用目录 | 每个应用显示实体、字段、关联、API 的汇总数量。 |
| MDB-03 | 点击应用 | 进入该应用详情，仅显示其资源。 |
| MDB-04 | 在详情切换应用 | 当前实体与各资源页签同步切换到目标应用。 |
| MDB-05 | 返回目录 | 恢复应用目录，不丢失已加载模型。 |

## 系统设置视觉回归

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| UI-SET-01 | 1440px 管理员云枢环境 | 标题、说明、表单、部署说明和操作栏在同一阅读列；无超宽输入框、遮挡或重叠。 |
| UI-SET-02 | 各设置子菜单 | 使用统一字号、卡片圆角、间距、弱化文字和按钮布局，不出现页面间风格跳变。 |
| UI-SET-03 | 900px / 620px 断点 | 表单、标题状态、操作区和元数据浏览自动重排，无横向滚动和控件覆盖。 |

## 日志分析回归

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| LOG-01 | 打开日志分析 | 不跳转旧审计页；显示调用、成功/失败、Token、耗时汇总。 |
| LOG-02 | 查询日志明细 | 输入/输出为脱敏摘要，模型、调用类型、状态、Token 和耗时可查看。 |
| LOG-03 | 缺少 provider usage | Token 显示“—”，不按字符数估算。 |
| LOG-04 | 时间/状态/动态业务意图筛选与分页 | 意图选项从实际日志记录动态生成；新增业务意图无需修改前端枚举，条件在后端生效，单页不超过 100 条。 |
| LOG-05 | 旧 Agent Run 追溯 | `/audit` 仍可按 Run ID 查看技术详情，不作为系统设置主入口。 |
