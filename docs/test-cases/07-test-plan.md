# 测试计划

> 文档类型：总测试计划｜状态：持续维护。专项用例与实际结果以 `08`、`14`–`18` 等测试文档为准；本计划不把规划功能计为通过。

## 1. 测试目标

验证 CPClaw 是否满足产品设计蓝图和技术设计蓝图中的核心目标：用户可以通过对话式入口，基于本地云枢元数据知识图谱，安全、可解释、可审计地查询和操作云枢应用。

## 2. 单元测试

- 槽位抽取。
- 本地元数据能力匹配。
- 非向量多路召回与候选排序。

- DAG 执行计划生成。
- Reflection 判断。

- 记忆召回和写入规则。

### 2.2 模型网关

### 2.3 安全

- 日志脱敏。

### 2.4 云枢连接器

### 2.5 附件

## 4. E2E 测试

使用 Playwright 测试：

1. 打开前端。
2. 进入设置页。
3. 填写云枢连接信息。
4. 配置模型 API 地址、API Key 和模型名称。
5. 配置模型是否支持思考模式。
6. 测试模型连接。
7. 测试云枢连接。
8. 同步云枢架构。
9. 新建会话。
10. 在对话框选择模型并启用或关闭思考模式。
11. 输入“查询我的销售订单数据”。
12. 检查返回摘要、Markdown 表格和执行步骤。
13. 输入“给第一条写一条跟进记录”。
14. 检查系统能解析上下文并要求确认。
15. 上传发票附件并要求填写报销单。
16. 检查字段映射、缺失字段提示和附件上传确认。
17. 查看历史会话和审计记录。
18. 验证“COMPLETED”等系统生命周期状态未作为项目/销售业务阶段进入分析图表与结论。

## 5. 安全验收

- Git diff 中没有明文密码、Token、Cookie、Session ID、API Key。
- 日志中敏感字段脱敏。
- 设置接口不返回密码、API Key 或密文内容。
- 模型调用摘要不包含敏感凭据。
- 附件解析结果不泄露敏感原文。
- 删除、批量修改、流程提交、业务 Action、附件上传均需要确认。
- 未确认或确认过期的高风险操作不得执行。
- `.env`、本地 Claude 配置、浏览器状态、日志和密钥文件不得入库。
- 高风险写操作的确认应阻断过期、重复确认；未实现的新增/更新/流程/Action 不得显示为已执行成功。

## 6. MVP 验收标准

- Vue 3 前端可启动。
- Spring Boot 后端可启动。
- MySQL 配置可连接。
- 会话和消息可保存。
- 设置可保存，敏感凭据加密。
- 运行服务仅连接显式配置的 MySQL；H2 仅可由测试 JVM 使用。
- 模型配置可保存并用于对话。
- 对话框支持模型选择和思考模式开关。
- 云枢元数据可同步到本地 MySQL。
- Agent 检索只访问本地 Metadata Index。
- Agent 可完成查询类模拟链路。
- 高风险操作确认机制可阻断未确认执行。
- 附件上传和解析链路具备基础能力。
- 文档按“产品设计蓝图、技术设计蓝图、专项详细设计、测试用例”分层存储在 `docs/`。
- 日志分析、模型预检和真实环境验证分别有独立可追溯测试记录；结论明确区分自动化、真实环境与未验证项。
### 凭据恢复回归

- 使用错误密钥读取历史密文：设置接口返回 `credentialStatus=unreadable`，不得返回英文解密异常。
- 模型、个人云枢、管理员云枢测试：HTTP 不应因解密失败而返回 500，消息应指导重新录入。
- 重新录入同一模型 API Key：覆盖原密文，不新增重复模型，状态恢复为 `available`。
- 删除模型配置：二次确认后删除模型和 API Key，历史会话、日志和 Token 记录保持不变。

### Token 用量回归

- 非流式响应包含标准 `usage` 时，输入、输出和总 Token 均落库。
- 流式响应在 `[DONE]` 后返回 usage，仍能记录总 Token。
- 兼容响应使用 `input_tokens/output_tokens` 或嵌套 `response.usage` 时，仍能记录。
- Agent 一次执行包含多次模型调用时，日志分析按执行汇总 Token；没有 usage 时显示“—”。
- 用量看板按 `Asia/Shanghai` 正确输出日、周、月桶与模型桶；调用次数包含全部记录，Token 仅汇总模型实际返回的 usage。
- 设置菜单将“用量看板”与“调用明细”分开；前者可切换日/周/月趋势和查看模型分布，后者保留筛选、分页和单条详情。

### 元数据同步日志回归

- 调用元数据同步后，`GET /api/metadata/sync-logs` 返回最近成功时间与倒序日志；首条记录为成功且范围统计完整。
- 管理员连接、权限或上游响应异常时，当前同步失败记录仍持久化，失败摘要脱敏；已存在的元数据、图谱和最近一次成功时间不得被清空。
- 从旧版本升级时，历史图谱快照会回填为可展示的同步历史；图谱快照清理后，新同步日志仍保留。
